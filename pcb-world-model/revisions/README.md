## How to Run & Demo the Active `rev14` System

1. **Run the Full 78-Test Verification Suite (`rev1`–`rev14`, incl. Rigid-Flex 8L HDI, Cross-Hatched $85\Omega$ PCIe Gen 4, Skew Matching & Under-BGA PDN Migration):**
   ```bash
   uv run pytest pcb-world-model/tests -v
   ```
2. **Run the `rev14` `B15` & `B15a`, `rev13` `B14` & `B14a–c`, `rev12` `B13`, and `B1–B5` Benchmark Suites (Standard & Blind Modes):**
   ```bash
   uv run python pcb-world-model/scripts/05_run_benchmarks.py --rev14
   uv run python pcb-world-model/scripts/05_run_benchmarks.py --rev14 --blind
   uv run python pcb-world-model/scripts/05_run_benchmarks.py --rev13
   uv run python pcb-world-model/scripts/05_run_benchmarks.py --rev12
   uv run python pcb-world-model/scripts/05_run_benchmarks.py --revision "rev14"
   uv run python pcb-world-model/scripts/05_run_benchmarks.py --revision "rev14-blind" --blind
   ```
3. **Launch the Live 2D/3D PBR, Schematic, Mixed-Signal & Rigid-Flex Workstation (`REV 14`):**
   ```bash
   uv run uvicorn ui.server:app --app-dir pcb-world-model --port 8050
   ```
